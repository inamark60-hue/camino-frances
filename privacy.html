Responsable del proyecto

BUEN CAMINO es una aplicación gratuita creada por Ignacio Marquiegui como herramienta de apoyo al peregrino del Camino Francés.

Datos guardados en el dispositivo

La versión actual no requiere una cuenta de usuario. Favoritos, etapas realizadas de Mi Camino, “me gusta”, contadores y comentarios se guardan en el almacenamiento local del navegador. Las fotos añadidas por el usuario se guardan en una base de datos local del dispositivo.

Ubicación

La ubicación GPS se solicita únicamente cuando el usuario activa una función que la necesita. Se utiliza para mostrar la posición en el mapa o calcular la carta de estrellas y constelaciones para ese lugar. BUEN CAMINO no mantiene un historial propio de ubicaciones. La brújula usa temporalmente los sensores de orientación del dispositivo y no guarda el rumbo. Al utilizar mapas u otros servicios externos, el navegador puede contactar con sus proveedores.

Servicios externos

Para ofrecer determinadas funciones, el navegador puede conectarse con proveedores externos, entre ellos OpenStreetMap/OpenTopoMap, OpenFreeMap, KartaView, Open-Meteo, AEMET, Open Pilgrimages, Overpass, BRouter, Wikimedia Commons, Google Maps/Google Earth y Wikiloc. Cada proveedor aplica sus propias condiciones y políticas, y puede recibir información técnica habitual de una conexión web, como la dirección IP.

Comentarios, likes, visitas y fotos

En la versión actual estos elementos son locales al dispositivo y no constituyen una red social pública. Las fotos del usuario no se publican automáticamente en Internet.

Donaciones

La opción solidaria abre directamente la web oficial de Save the Children. BUEN CAMINO no procesa, gestiona ni recibe las donaciones.

Borrado de datos

Desde Inicio → Acerca de · Privacidad · Datos se puede solicitar el borrado de los datos locales de BUEN CAMINO almacenados en el dispositivo. El navegador o el sistema operativo también permiten eliminar los datos del sitio o desinstalar la PWA.

Uso responsable

BUEN CAMINO es una herramienta de ayuda y no sustituye la señalización física, las indicaciones de autoridades y responsables del Camino, los avisos meteorológicos oficiales ni los servicios de emergencia. En una emergencia en España, utiliza el 112.

Datos astronómicos

La vista Estrellas y constelaciones puede descargar catálogos abiertos de Celestial Data/d3-celestial (estrellas, constelaciones y objetos Messier). Se pueden guardar en la caché del dispositivo para acelerar usos posteriores. No contienen datos personales. El buscador celeste funciona localmente sobre esos catálogos y las posiciones calculadas del Sistema Solar; el texto buscado no se envía a un servidor de BUEN CAMINO.
